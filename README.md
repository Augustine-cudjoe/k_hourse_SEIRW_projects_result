# Reproducibility Code for a Multi-House SEIRW Model

## Overview

This repository contains the Python code used to reproduce the numerical illustrations in the manuscript:

**A \(k\)-House SEIRW Model with Directed Environmental Movement: Spectral Thresholds, Edge-Gradient Sensitivity, and Mixed-Pathway Amplification**

The study investigates how directed movement between houses affects the basic reproduction number through environmental transmission pathways. It examines spectral properties, movement derivatives, directed-edge sensitivities, strong-mixing behaviour, and different movement-response regimes.

The numerical experiments use deterministic matrix calculations and eigenvalue computations. No fitted epidemiological data or external epidemiological dataset is required to run the examples.

## Mathematical framework

The next-generation matrix is

\[
K(\alpha)=BP+HM_\alpha^{-1}D_\xi P,
\]

where

\[
M_\alpha=D_\omega+\alpha Q.
\]

Here, \(\alpha\) denotes movement intensity, \(Q\) is the directed movement generator, and the remaining matrices encode direct transmission, environmental transmission, and model-specific parameters.

The basic reproduction number is defined by

\[
R_0(\alpha)=\rho(K(\alpha)),
\]

where \(\rho(\cdot)\) denotes the spectral radius.

The numerical experiments illustrate that increasing movement intensity does not necessarily increase or decrease the full reproduction number. Its response depends on the network structure and the alignment of the relevant spectral quantities.

## Numerical experiments

The repository reproduces three principal configurations.

| Configuration | \(R_0(0)\) | \(R_0(20)\) | Observed response |
|---|---:|---:|---|
| Two-house model | 7.0000 | 8.8694 | Increasing |
| Five-house model | 3.7198 | 3.4050 | Decreasing |
| Four-house model | 3.8431 | 3.7837 | Nonmonotone |

For the four-house configuration, the minimum on the numerical grid occurs at approximately \(\alpha=0.85\), with \(R_0\approx3.7789\).

For the two-house configuration, the direct and environmental components are \(R_D=4\) and \(R_E=3\), respectively, and the analytical derivative at zero movement is

\[
R_0'(0)=\frac{21}{2}=10.5.
\]

For the five-house configuration, the calculated initial derivative is approximately \(-0.6485382\), and the strong-mixing environmental limit is approximately \(2.6106\).

These are numerical illustrations for the specified parameter configurations, not a universal classification theorem.

## Repository contents

- `reproduce_results.py` — main Python script for numerical calculations and figure generation.
- `figures/` — generated figures for the manuscript.
- `results/` — numerical summaries and tabulated movement-response data, where generated by the script.
- `tests/` — automated regression tests.
- `requirements.txt` — Python dependencies.
- `.gitignore` — excludes unnecessary generated or temporary files.

## Requirements

- Python 3.10 or later
- NumPy
- Matplotlib
- pytest (for running the test suite)

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
cd YOUR-REPOSITORY
```

Replace `YOUR-USERNAME` and `YOUR-REPOSITORY` with the actual GitHub account name and repository name.

Install the dependencies:

```bash
python -m pip install -r requirements.txt
python -m pip install pytest
```

## Reproduce the numerical results and figures

From the repository root, run:

```bash
python reproduce_results.py
```

The script prints the numerical summaries and generates the figures in the `figures/` directory.

To run the automated tests:

```bash
python -m pytest tests -q
```

The current regression test suite contains three tests covering the two-house values, five-house endpoints, and four-house nonmonotone response.

## Reproducibility notes

The five-house configuration uses a fixed random seed, making its generated movement network reproducible. The two-house and four-house configurations use specified parameter values.

The numerical results reported above are rounded for readability. Small differences in the last displayed digit may arise from numerical precision or rounding.

The automated tests check selected numerical outputs; they do not independently prove the analytical results or validate every point on every plotted curve.

## Data availability

No external epidemiological dataset is required for these numerical experiments. The results are calculated from the model parameters specified in the code.
